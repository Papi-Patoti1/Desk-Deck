# Desk-Deck
Custom macro keypad software that connects to an Arduino via serial port to control PC shortcuts and apps.

Just a Python script to read the serial from an Arduino Uno which is connected to an old telephone's keypad and perform specific macros. 
Basically a Stream Deck software for DIY stream decks (can even be used with simple push buttons).

1. Click on **Releases** on the right side of this page.
2. Download the `.exe` file.
3. Run it.
